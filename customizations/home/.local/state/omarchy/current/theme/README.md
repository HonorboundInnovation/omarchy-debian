# Neural Acid

A custom Omarchy theme for Debian: black surfaces, acid green focus, deep purple depth, and cobalt blue edges. The wallpaper is original AI-generated art.

Activate with `omarchy-theme-set "Neural Acid"`. Omarchy generates matching terminal, editor, browser, and system themes from `colors.toml`.

Wallpaper: `backgrounds/neural-core.png` (1672 × 941). The original generated image is preserved in Codex's generated images directory.
